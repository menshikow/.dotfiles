#+TITLE: Learn Neovim — Path to Mastery
#+DATE: 2026-05-29

* Core Skills (learn in order)

** 1. Modal Editing Fundamentals
- Understand normal / insert / visual / command-line / select modes
- =h j k l=, =w b e=, =0 $=, =^=, =gg G=, =H M L=
- =i a o I A O=, =c d y p=, =u <C-r>=, =.=
- =f F t T=, =; ,=, =* #=, =%=
- =ciw=, =ci"=, =cit=, =daW=, =ysiw"= (surround)
- =v V <C-v>= (character / line / block visual)

** 2. The Vim Way (Composable Editing)
- Verbs + nouns: =d2w=, =c3j=, =yip=, =>G=
- Dot-repeat: edit once, repeat with =.=
- Record macros with =q=, repeat with =@=
- Build an intuition for the *minimum keystrokes*

** 3. Neovim-Specific
- Built-in LSP client (=vim.lsp.*=)
- Built-in treesitter (=vim.treesitter.*=)
- =vim.ui=, =vim.notify=, =vim.fs=
- Lua as a first-class config language
- =vim.api.nvim_*= API
- Autocommands (=vim.api.nvim_create_autocmd=)
- User commands (=vim.api.nvim_create_user_command=)

** 4. Lua Config Mastery
- =require()=, module patterns
- =vim.opt.*=, =vim.g.*=, =vim.b.*=, =vim.bo.*=, =vim.wo.*=
- =vim.keymap.set()= (all modes, buffers, desc)
- =vim.schedule()=, =vim.defer_fn()=
- Writing Lua plugins / modules

** 5. Plugin Management
- Understand lazy.nvim: =lazy=, =event=, =keys=, =cmd=, =opts=, =config=, =dependencies=
- Plugin spec anatomy (lazy-loading, conditions, overrides)
- How to read plugin source code

* Projects to Build (increasing difficulty)

** Beginner
1. Write your own =init.lua= from scratch (no distro)
2. Create a simple statusline with =vim.o.statusline=
3. Write a custom colorscheme override (highlight groups)

** Intermediate
4. Build a custom picker using telescope's built-in utilities
5. Write a small Lua plugin (e.g. a scratch buffer manager)
6. Create a custom LSP action (e.g. =vim.lsp.buf.code_action= wrapper)
7. Implement a macro manager / recorder helper
8. Write an autocommand that auto-formats on save

** Advanced
9. Write a treesitter-based textobject plugin (=nvim-treesitter-textobjects= style)
10. Build a DAP UI extension
11. Write a custom completion source for nvim-cmp
12. Contribute a PR to Neovim core or a plugin you use
13. Port an existing vim plugin to Lua
14. Write a fuzzy finder from scratch using =vim.ui.select=

* Concepts to Master

- =&makeprg=, =:make=, =:grep=, quickfix list (=:copen=, =:cnext=)
- =:diffthis=, =:diffoff= — vimdiff workflow
- =:normal=, =:global= — ex-mode batch editing
- =:registers=, =<C-r>= expression register
- =:&lt;C-f&gt;= in command-line mode — command-line window
- =:abbrev=, =:map-<expr>= — abbreviations and expression mappings
- =vim.inspect()= — debugging Lua tables
- =--cmd=, =--headless=, =--startuptime= flags
- Jump list (=<C-o> <C-i>=) and change list (=g; g,=)
- Quicklist / loclist workflows

* Daily Habits for Mastery

- Read =:help= for any feature you use once a week
- Ask "is there a faster way?" when doing repeated edits
- Watch experienced users (streams / videos) — learn their patterns
- Keep your config in version control and refactor it often
- When a plugin breaks, read the source to fix it instead of searching
- Contribute small fixes to plugins you use
