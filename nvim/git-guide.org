#+TITLE: Git in Neovim — neogit + diffview Guide
#+DATE: 2026-05-29

* Quick Start

Open neogit status buffer:

: <leader>gs

This is your Magit-like dashboard. All git operations start from here.

* Keybindings (in neogit status buffer)

** Basic
- =?= :: toggle help popup
- =q= :: close neogit
- == :: refresh status

** Staging / Unstaging
- =s= :: stage file / hunk under cursor
- =S= :: stage all
- =u= :: unstage file / hunk
- =U= :: unstage all

** Committing
- =c= :: commit popup (choose =c= again for normal commit)
- =C= :: amend commit
- =cc= :: normal commit (opens commit message buffer)
- =ca= :: amend
- =cf= :: fixup
- =cw= :: reword

** Branching
- =b= :: branch popup
- =bb= :: create branch
- =bc= :: checkout branch
- =bd= :: delete branch
- =bm= :: merge
- =br= :: rebase

** Log / History
- =l= :: log popup
- =ll= :: log current file
- =ld= :: log range (diff)

** Diffing
- =d= :: diff popup
- =dd= :: diff working tree
- =dr= :: diff range (between commits)

** Other
- =x= :: discard changes
- =v= :: revert
- =r= :: rebase popup
- =f= :: fetch
- =P= :: push
- =p= :: pull
- =t= :: tag popup
- =!= :: run =git= command

* Commit Message Buffer

When committing (=cc=), a new tab opens:
- Write commit message
- =:wq= or =<C-c><C-c>= to confirm
- =:cq= or =<C-c><C-k>= to abort

* Diffview (diffing / reviewing)

Opened with =<leader>gd= or from neogistatus buffer.

** In diffview
- =q= :: close diffview
- =<Tab>= :: focus file list panel
- =<S-Tab>= :: focus diff panel
- =j k= :: navigate files
- =d= :: toggle diff against base
- =C= :: cycle layout
- =o= :: open file in new tab
- =gb= :: select base branch (compare against)
- =gl= :: open log

** Diffview file history
: <CMD>DiffviewFileHistory<CR>

** Compare with branch
: <CMD>DiffviewOpen origin/main...HEAD<CR>

* Telescope Git Integration

- =<leader>gb= :: browse / switch branches
- =<leader>fc= :: =Telescope git_commits= (walk commit history)

: Telescope git_status      # files changed
: Telescope git_bcommits    # commits for current file
: Telescope git_stash       # stashes
: Telescope git_branches    # branch picker

* Workflow Example

1. =<leader>gs= — open status
2. =s= — stage relevant hunks
3. =cc= — write commit message, =:wq=
4. =P= — push
5. =<leader>gl= — view log to verify

* Neovim Built-in Git (no plugins)

If you don't want neogit, Neovim has built-in git commands:

- =:Gitsigns= (from gitsigns.nvim — already installed)
- =<leader>hs= — stage hunk
- =<leader>hr= — reset hunk
- =]c= / =[c= — next / prev hunk
- =:!git %= — run git on current file
